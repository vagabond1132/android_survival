## 一、编码规范

### 1.1 C++ 规范

#### 1.1.1 版本与特性
- **C++ 标准**：C++17 / C++20
- **编译器**：GCC 12+ / Clang 16+
- **特性使用**：
  - ✅ 使用 `auto`（类型明显时）
  - ✅ 使用智能指针
  - ✅ 使用范围 for
  - ✅ 使用 `std::optional`, `std::variant`
  - ⚠️ 谨慎使用模板（性能 vs 可读性）
  - ❌ 避免 C 风格代码
  - ❌ 避免 `using namespace`

#### 1.1.2 命名规则

| 类型 | 规则 | 示例 |
|---|---|---|
| 类 / 结构体 | PascalCase | `class RecognitionEngine` |
| 命名空间 | 全小写 | `namespace outdoor` |
| 函数 | camelCase | `recognizeImage()` |
| 成员变量 | m_ + camelCase | `m_recognitionEngine` |
| 静态成员 | s_ + camelCase | `s_instance` |
| 全局变量 | g_ + camelCase | `g_logger` |

bool RecognitionEngine::initialize(const QString& modelsDir) {
    if (m_initialized) {
        Logger::warn("RecognitionEngine already initialized");
        return true;
    }
    
    // 加载模型
    QString modelPath = modelsDir + "/plant_v1.param";
    QString weightPath = modelsDir + "/plant_v1.bin";
    
    if (d_->net.load_param(modelPath.toStdString().c_str()) != 0) {
        Logger::error("Failed to load model param: " + modelPath);
        return false;
    }
    
    if (d_->net.load_model(weightPath.toStdString().c_str()) != 0) {
        Logger::error("Failed to load model weight: " + weightPath);
        return false;
    }
    
    m_modelsDir = modelsDir;
    m_initialized = true;
    
    Logger::info("RecognitionEngine initialized: " + modelPath);
    return true;
}

    // 3. 后处理
    // ...
    
    result.confidence = 0.92f;
    result.speciesId = "plant_rhododendron";
    return Status::Success;
}

#### 1.1.6 错误处理

**目标**: 消除 5 套散乱的错误表达(裸 `return false` / `try{...}catch(e){/*ignore*/}` / 空 `""` / 空 `{}` / 半成品 `{ok,error}`),统一通过 `Result<T>` 包装 + QML 端 Toast 反馈。

**5 阶段架构重构演进 (2026-09-20 起)**:

| 阶段 | 状态 | 内容 |
|---|---|---|
| Phase 1 | ✅ 命名规范落地 | 创建 `命名规范.md`,定义 Service 接口层命名 |
| Phase 2.1+2.2 | ✅ 基础设施 | `src/core/Result.h` + `ServiceErrors.h` + `QmlResultBridge.h` + `DbHelper` + 5 个 service 接入 (Phase 2.3/2.4 SpeciesServiceBase CRTP 留到后续) |
| Phase 3 | ✅ 设计模式 + QML 组件 | `RuleConditionStrategy` + `RuleConditionFactory` + `ServiceListModel.qml` + `DangerChip.qml` + `Toast.qml` + `DetailLoader.qml` + `SpeciesServiceRegistry.qml` |
| Phase 4 | ✅ 签名统一 (2026-09-20) | 9 个 `removeXxx` → `deleteXxx`, 4 个 `getXxx(id)` → `getById(id)`, 2 个 `getBySeason` → `getByMonth`, 详细对照表见 [命名规范.md](./命名规范.md) v0.2 |
| Phase 5 | ⏳ 全量切换 | 18 个写操作 / 23 个查询操作切到 Result<T> 包装 |

// src/core/Result.h
namespace outdoor {

enum class ServiceErrorCode {
    Ok, NotFound, InvalidArgument, PermissionDenied,
    DbError, IoError, NetworkError, InternalError, Unknown
};

struct ServiceError {
    ServiceErrorCode code = ServiceErrorCode::Ok;
    QString message;
    QString context;       // 哪个 service / method 报错
    QVariantMap details;    // 扩展 (SQL lastError 等)
};

template <typename T>
struct Result {
    T value{};
    ServiceError error;
    bool isOk() const { return error.isOk(); }
