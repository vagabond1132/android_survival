### 5.1 QtQuick3D 源码预置包 (Dockerfile 必带)

| 包 | 版本 | 大小 | 来源 | 备注 |
|---|---|---|---|---|
| `qtquick3d-6.7.2.zip` | 6.7.2 (alpha1) | 53MB | [mirrors.tuna.tsinghua.edu.cn/qt/](https://mirrors.tuna.tsinghua.edu.cn/qt/) | aqt 在 Qt 6.7.2 Android 平台不提供 `libQt6Quick3D_<abi>.so` 主库, 需手动预置源码 + `qt-cmake` 交叉编译 |
| `qtquick3d-assimp-5.4.1.zip` | 5.4.1 | 53MB | [github.com/assimp/assimp](https://github.com/assimp/assimp) v5.4.1 | qtquick3d 源码 zip 的 `src/3rdparty/assimp/` 是空目录 (仅 metadata), 必须用此 zip 摆位后 Qt 才能编 vendored assimp 插件 |

**Dockerfile 关键命令** (详见 [09-讨论记录/06-qtquick3d-assimp构建修复.md](../09-讨论记录/06-qtquick3d-assimp构建修复.md)):

```dockerfile
COPY qtquick3d-6.7.2.zip /tmp/qtquick3d-6.7.2.zip
COPY qtquick3d-assimp-5.4.1.zip /tmp/qtquick3d-assimp-5.4.1.zip
# 摆位: assimp zip 的 code/include/contrib 移到 3rdparty/assimp/src/
# 补丁: ioapi.c 注入 IOAPI_NO_64 + 改 ftello→ftell / fseeko→fseek
# 编译: -DQT_FEATURE_system_assimp=OFF (不依赖 apt libassimp-dev)
```

## 8. 关键兼容性警告

| 风险 | 原因 | 现状 |
|------|------|------|
| Qt 5 → Qt 6 类名漂移 | `org/qtproject/qt5/android/QtNative` → `org/qtproject/qt/android/QtNative` | ✅ 已修 (AndroidPlatform.cpp) |
| Qt 6.5+ 移除 mapbox 插件 | QtLocation 商业插件, Qt 6 改用 osm/esri/here | ✅ 已修 (MapPage.qml) |
| NDK 26.1 + c++_shared + R8 | 可能裁剪 `libc++_shared.so` 内部符号 | ⚠️ 需验证, R8 默认保留 |
| AGP 8 namespace 模式 | 不识别 buildscript.repositories | ✅ 已修 (settings.gradle FAIL_ON_PROJECT_REPOS) |
| R8 裁剪 native 方法名 | JNI 符号 `Java_...` 找不到 | ✅ 已修 (proguard-rules.pro -keepclasseswithmembernames) |
| debug.applicationIdSuffix | applicationId 与 namespace 不一致 | ✅ namespace 固定, applicationId 可变, Java 类路径不变 |

## 9. 升级检查清单

升级前**必须**核对:

- [ ] Qt 升级: `aqt install-qt linux android <新版本>` + CMake `find_package(Qt6 <新版本>)` + Dockerfile
- [ ] NDK 升级: 验证 Qt 6.7 兼容性 (官方支持 25.x/26.x)
- [ ] AGP 升级: 同时升级 Gradle (查 §3.1 兼容矩阵)
- [ ] JDK 升级: AGP 8.x 必须 JDK 17+
- [ ] AndroidX 库升级: 主要看 `material` (主题) 和 `lifecycle-service` (前台服务)
- [ ] security-crypto 1.1.0-alpha06 → 1.1.0-stable (生产前)
- [ ] 删除冗余 Qt 模块 (Sensors/Network/Concurrent) 以减小 APK
