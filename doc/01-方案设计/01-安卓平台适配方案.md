## 一、为什么选 Android 优先

### 1.1 户外用户结构
- 国内户外 / 登山 / 徒步人群中，**Android 占比 80%+**
- iPhone 在三防 / 长续航 / 卫星通信上占优但份额小
- 国产户外手机（如 AGM、Unihertz）几乎全 Android
- **三防手机 + 长续航**是户外用户首选

### 1.2 Android 的技术优势
- **APK 体积控制更灵活**（App Bundle 按需分发）
- **NDK + 任意 C++ 库**（适合我们 Qt/C++ 栈）
- **NNAPI 硬件加速**（端侧 AI 推理快）
- **文件存储访问**（离线资源管理方便）
- **后台限制相对宽松**（iOS 后台更严）

### 1.3 适配复杂度
- **碎片化严重**：100+ 品牌、10000+ 机型
- **深度定制系统**：MIUI、EMUI、ColorOS、HarmonyOS 等
- **权限管理激进**：尤其国产 ROM
- **后台管控严**：尤其华为、小米

## 三、Qt 6 for Android 关键点

### 3.1 Qt 优势（对你这种场景）

- ✅ 一次编写，Android / iOS / 嵌入式 Linux 多端发布
- ✅ QML 性能 + 触摸体验现代
- ✅ C++ 业务逻辑直接运行（性能接近原生）
- ✅ 直接访问 NDK API 和硬件加速

### 3.2 Qt for Android 限制

- ⚠️ 包体积比纯原生大（基础 5-10MB）
- ⚠️ 部分高级 Android 特性需 JNI 桥接
- ⚠️ 启动比纯 Kotlin 慢 200-500ms（可优化）
- ⚠️ 部分国产 ROM 优化差（需深度适配）

### 3.3 Qt 6.7 关键改进

- Android 13 (API 33) 全面支持
- OpenSSL 3.x 集成
- Gradle 8 + AGP 8 支持
- 改进的 RHI 渲染（Vulkan 后端）
- 性能提升 20-30%

### 3.3.1 Qt 5 → Qt 6 兼容性陷阱（重要）

升级到 Qt 6 时, 以下类名 / API 必须修改, 否则会 `jniRegisterNativeMethods` 找不到类 → 启动崩溃:

| Qt 5 路径 | Qt 6 路径 | 影响 |
|-----------|-----------|------|
| `org/qtproject/qt5/android/QtNative` | `org/qtproject/qt/android/QtNative` | 4 处静态方法调用, 不改 `getActivity()` 拿到 null |
| `org/qtproject/qt5/android/QtApplication` | `org/qtproject/qt/android/QtApplication` | 反射类名 |
| `org/qtproject/qt5/android/QtMessageDialogHelper` | `org/qtproject/qt/android/QtMessageDialogHelper` | 消息对话框 |

**参考实现**: `src/platform/AndroidPlatform.cpp:23` `constexpr const char* kQtNativeClass = "org/qtproject/qt/android/QtNative";`

**Qt 6 插件变化**:
- QtLocation **mapbox 插件**已移除, 改用 `osm` / `esri` / `here`
- `osm` 插件参数: `osm.mapping.host` (不是 `.custom.host`)
- QtMultimedia 在 Android 上需要 `CAMERA` / `RECORD_AUDIO` 权限

**Android 12+ adaptive icon 规范**:
- `mipmap-anydpi-v26/ic_launcher.xml` 必须区分 `<background>` 和 `<foreground>`
- foreground PNG 必须是**透明背景**, logo 居中 66% 区域
- background 可以是 color 或 drawable

## 四、权限申请方案

### 4.1 权限分级策略

| 权限 | 申请时机 | 必要性 |
|---|---|---|
| **相机** | 首次进入"识别"页面 | 必须 |
| **存储（图库）** | 首次选择相册图片 | 必须 |
| **位置** | 首次使用地图 / 出行规划 | 推荐 |
| **电话（拨打 120）** | 首次使用"一键求救" | 关键 |
| **短信** | 首次发送求救短信 | 关键 |
| **网络** | 默认 | 必要（更新离线包用） |
| **闪光灯** | 首次使用手电 | 推荐 |

### 4.2 运行时权限申请（Qt 实现）

```cpp
class PermissionManager : public QObject {
    Q_OBJECT
public:
    enum Permission {
        Camera,
        Storage,
        Location,
        Phone,
        Sms,
    };
    Q_ENUM(Permission)
    
    Q_INVOKABLE void requestPermission(Permission perm, 
                                       std::function<void(bool)> callback);
    Q_INVOKABLE bool checkPermission(Permission perm);
    
private:
    QAndroidJniObject m_activity;
};
```

### 4.3 JNI 桥接代码

```java
// Java 侧 - MainActivity.java
public class MainActivity extends QtActivity {
    
    private static final int PERMISSION_REQUEST_CODE = 1001;
    
    public void requestPermission(final String perm, 
                                  final long callbackPtr) {
        runOnUiThread(new Runnable() {
            @Override
            public void run() {
                if (ContextCompat.checkSelfPermission(this, perm) 
                    != PackageManager.PERMISSION_GRANTED) {
                    ActivityCompat.requestPermissions(
                        this, 
                        new String[]{perm}, 
                        PERMISSION_REQUEST_CODE
                    );
                } else {
                    // 已授权，回调 C++
                    nativeCallback(callbackPtr, true);
                }
            }
        });
    }
    
    public void makeEmergencyCall(String number) {
        Intent intent = new Intent(Intent.ACTION_CALL);
        intent.setData(Uri.parse("tel:" + number));
        intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
        startActivity(intent);
    }
    
    public void sendEmergencySms(String number, String message) {
        SmsManager sms = SmsManager.getDefault();
        sms.sendTextMessage(number, null, message, null, null);
    }
}
```

### 4.4 拒绝授权的兜底

- 相机被拒：引导到系统设置
- 存储被拒：仅能拍照，不能读相册
- 位置被拒：地图不可用，提示手动选择区域
- 全部被拒：仍可查看已下载的离线内容

### 4.5 国产 ROM 特殊处理

- **MIUI**：自启动 + 后台运行要单独申请
- **EMUI / HarmonyOS**：关联启动要单独申请
- **ColorOS**：电池优化白名单
- **OneUI**：无障碍服务
- **OnePlus**：电池优化

**关键提示文案**：
> "为确保紧急情况 App 能正常拨打 120 并发送位置，请允许 [荒野手册] 在后台运行并加入电池优化白名单"

## 七、性能优化

### 7.1 启动优化

| 阶段 | 目标 | 措施 |
|---|---|---|
| 进程创建 | < 500ms | 减少 NDK 库 |
| 主 Activity | < 1s | 延迟加载非关键模块 |
| 首屏渲染 | < 2s | 启动图 + 骨架屏 |
| 可交互 | < 3s | 懒加载 + 异步 |

**Qt 启动优化**：
- 减少 QML 初始加载
- 延迟实例化非首屏页面
- 预编译 QML
- AOT 编译（Qt 6.5+）

### 7.2 内存优化

| 措施 | 节省 |
|---|---|
| 大图懒加载 | 30% |
| 视频缩略图 | 20% |
| 数据库分页查询 | 15% |
| 缓存 LRU 控制 | 10% |

**目标**：App 运行期 < 300MB，识别时峰值 < 500MB

### 7.3 相机性能

- **CameraX 替代 Camera2 API**（Google 推荐）
- 后台线程处理图像
- 避免主线程阻塞
- 预览帧可选识别（实时模式）

### 7.4 图像处理性能

- OpenCV 多线程
- NEON / Vulkan 加速
- 异步识别（不阻塞 UI）
- 取消机制（用户切换页面时取消当前识别）

### 7.5 包体积优化

| 阶段 | 目标 | 措施 |
|---|---|---|
| 基础包 | < 30MB | 模型延迟下载 |
| 按需下载 | 50-200MB | 区域化 |
| App Bundle | 节省 30% | Google Play 推荐 |

**AAB 拆分**：
- 基础 APK：20-30MB
- 模型按 ABI 拆分：arm64-v8a / armeabi-v7a / x86_64
- 资源按语言 / DPI 拆分

### 7.6 帧率与流畅度

- 列表使用 `QListView` + 虚拟化
- 图片使用 QML 异步加载
- 避免 QML 嵌套过深
- 复杂动画用 Lottie 或 RHI 渲染

## 八、省电与后台策略

### 8.1 省电原则

户外用户最关心：**电池续航**。

| 措施 | 说明 |
|---|---|
| 屏幕暗模式 | 户外强光下也省电 |
| 降低帧率 | 静态页面 30fps |
| 关闭非必要传感器 | GPS 仅在需要时开 |
| 后台严格管控 | 识别时只保留必要服务 |
| 闪光灯限流 | 防止过热 |

### 8.2 后台运行策略

#### 场景 1：日常使用
- 识别后立即释放资源
- 1 分钟后进入低功耗

### 12.4 紧急求救服务（Java）

```java
// EmergencyService.java
public class EmergencyService extends Service {
    
    private LocationManager locationManager;
    private String[] emergencyNumbers = {"120", "110", "119"};
    
    @Override
    public int onStartCommand(Intent intent, int flags, int startId) {
        startForeground(1, buildNotification());
        startLocationTracking();
        return START_STICKY;
    }
    
    private void startLocationTracking() {
        locationManager = (LocationManager) getSystemService(LOCATION_SERVICE);
        
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.R) {
            // Android 11+ 需要前台服务
        }
        
        locationManager.requestLocationUpdates(
            LocationManager.GPS_PROVIDER,
            5000,  // 5 秒
            10,    // 10 米
            locationListener
        );
    }
    
    private final LocationListener locationListener = new LocationListener() {
        @Override
        public void onLocationChanged(Location location) {
            // 发送位置给紧急联系人
            sendLocationToContacts(location);
        }
    };
    
    public void sendSosToContacts(double lat, double lon) {
        // 读取紧急联系人
        String[] contacts = getEmergencyContacts();
        String message = String.format(
            "【紧急求救】我目前在经度%.6f, 纬度%.6f，需要帮助！",
            lon, lat
        );
        
        SmsManager sms = SmsManager.getDefault();
        for (String contact : contacts) {
            sms.sendTextMessage(contact, null, message, null, null);
        }
    }
    
    @Nullable
    @Override
    public IBinder onBind(Intent intent) {
        return null;
    }
}
```

## 十三、常见坑与解决方案

### 13.1 启动崩溃

**问题**：MIUI 上 Qt 应用启动后崩溃
**解决**：在 `MainActivity.java` 中延迟初始化 Qt

```java
@Override
public void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    // 延迟 Qt 初始化
    new Handler().postDelayed(() -> {
        // Qt 初始化代码
    }, 100);
}
```

### 13.2 相机权限被拒

**问题**：国产 ROM 上相机被默认拒
**解决**：友好的引导页 + 跳转到设置

### 13.3 后台被杀

**问题**：息屏 5 分钟后被清理
**解决**：前台服务 + 自启动白名单引导

### 13.4 模型加载慢

**问题**：30MB 模型冷启动 5 秒
**解决**：
- 异步预加载
- NDK 直接映射（mmap）
- 拆分加载

### 13.5 视频播放卡顿

**问题**：户外弱光下视频卡
**解决**：
- 降低分辨率（720p 而非 1080p）
- H.265 硬解
- 预加载到本地

### 13.6 GPS 在山区无信号

**问题**：偏远山区 GPS 定位慢
**解决**：
- AGPS 辅助定位
- 多源融合（GPS + GLONASS + 北斗 + Galileo）
- 上次已知位置兜底
- 显示定位精度

### 13.7 紧急联系号码格式

**问题**：110 / 120 / 119 在 Android 13 需 `ACTION_DIAL` 而非 `ACTION_CALL`
**解决**：
```java
if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.R) {
    intent = new Intent(Intent.ACTION_DIAL);  // 不需要权限
} else {
    intent = new Intent(Intent.ACTION_CALL);  // 需要 CALL_PHONE
}
```

### 13.8 鸿蒙兼容

**问题**：HarmonyOS NEXT 不再支持 Android APK
**解决**：
- 短期：兼容 HarmonyOS 4（Android 兼容）
- 长期：单独开发 HarmonyOS NEXT 原生版（ArkTS）
- 或用 Tauri / Flutter 重构

### 13.9 文件路径

**问题**：`getExternalStorageDirectory()` 在 Android 11+ 受限
**解决**：
```java
// Android 10+ 推荐
File dir = context.getExternalFilesDir(null);
File modelFile = new File(dir, "models/plant_v1.param");
```

### 13.10 JNI 内存泄漏

**问题**：长期运行内存持续增长
**解决**：
- 避免在 JNI 中持有 Java 对象引用
- 使用 WeakReference
- 定期检查
