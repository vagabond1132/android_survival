## 一、需求分析

### 1.1 用户痛点

| 场景 | 痛点 |
|---|---|
| **山区无信号** | 出发前看不到路线攻略 |
| **官方攻略陈旧** | 商业 App 路线更新慢 |
| **小众路线无收录** | 自驾 / 野路 App 找不到 |
| **个性化需求** | 想导入自己的 GPS 轨迹 |
| **跨平台数据** | 用其他 App 记录的轨迹想用 |
| **团队协作** | 领队路线想分享给队员 |

### 1.2 导入场景

#### 场景 A：导入第三方攻略
- 用户在网上找到 **两步路 / 六只脚 / 8264** 的路线详情
- 想离线保存到 App 内随时查看

#### 场景 B：导入 GPS 轨迹
- 用户自己用手机 / 手表记录了轨迹
- 想导入 App 看详情、添加危险点

#### 场景 C：导入文字攻略
- 复制 / 粘贴论坛精华帖
- 提取路线信息（起点、终点、距离、海拔）

#### 场景 D：导入官方发布
- 文旅局 / 登山协会发布的官方路线
- 通常是 PDF / Word / Excel 格式

#### 场景 E：分享导入
- 队友通过分享链接 / 文件 / 二维码发送路线
- 接收方一键导入

#### 场景 F：图片识别导入
- 拍路线图（含手绘 / 截图）
- OCR 提取信息

### 1.3 设计目标

| 目标 | 指标 |
|---|---|
| **多格式支持** | 至少 6 种主流格式 |
| **导入成功率** | > 95% |
| **导入速度** | < 5 秒（10MB 文件） |
| **离线可用** | 100% 离线导入 |
| **数据完整性** | 不丢失关键信息 |
| **易用性** | 3 步内完成导入 |

## 二、支持的数据格式

### 2.1 格式总览

| # | 格式 | 扩展名 | 用途 | 优先级 |
|---|---|---|---|---|
| 1 | **GPX** | `.gpx` | GPS 轨迹标准 | P0 |
| 2 | **KML** | `.kml` | Google Earth / 两步路 | P0 |
| 3 | **KMZ** | `.kmz` | KML 压缩 | P0 |
| 4 | **TCX** | `.tcx` | Garmin 训练数据 | P0 |
| 5 | **FIT** | `.fit` | Garmin / 手表 | P1 |
| 6 | **GeoJSON** | `.geojson` | 通用地理格式 | P1 |
| 7 | **CSV** | `.csv` | 自定义轨迹点 | P1 |
| 8 | **两步路专属** | `.gpx` / `.tdb` | 两步路导出 | P0 |
| 9 | **六只脚专属** | `.gpx` | 六只脚导出 | P0 |

| 11 | **PDF** | `.pdf` | 官方攻略 | P2 |
| 12 | **分享链接** | URL | 队友分享 | P0 |

## 五、核心实现

### 5.1 格式检测

```cpp
class FormatDetector {
public:
    enum Format {
        GPX, KML, KMZ, TCX, FIT, GeoJSON, CSV,
        OutdoorJSON, ImageOCR, PDF, Unknown
    };
    
    static Format detect(const QString& filePath);
    static Format detectFromContent(const QByteArray& content);
    
private:
    static Format detectByExtension(const QString& filePath);
    static Format detectByMagic(const QByteArray& content);
};

Format FormatDetector::detect(const QString& filePath) {
    QFile file(filePath);
    if (!file.open(QIODevice::ReadOnly)) {
        return Unknown;
    }
    
    // 1. 先看扩展名
    Format byExt = detectByExtension(filePath);
    if (byExt != Unknown) {
        return byExt;
    }
    
    // 2. 看文件头（magic bytes）
    QByteArray header = file.read(64);
    return detectByMagic(header);
}

Format FormatDetector::detectByMagic(const QByteArray& header) {
    if (header.contains("<?xml")) {
        if (header.contains("http://www.topografix.com/GPX") ||
            header.contains("gpx")) {
            return GPX;
        }
        if (header.contains("http://www.opengis.net/kml") ||
            header.contains("<kml")) {
            return KML;
        }
        if (header.contains("TrainingCenterDatabase") ||
            header.contains("tcx")) {
            return TCX;
        }
    }
    if (header.size() >= 2 && 
        (quint8)header[0] == 0x50 && (quint8)header[1] == 0x4B) {
        // ZIP 开头（KMZ 是 ZIP）
        return KMZ;
    }
    if (header.startsWith("{")) {
        return OutdoorJSON;  // 或 GeoJSON
    }
    if (header.size() >= 14 && 
        (quint8)header[8] == 0x46 && (quint8)header[9] == 0x49 &&
        (quint8)header[10] == 0x54) {
        return FIT;  // ".FIT" at offset 8-11
    }
    return Unknown;
}
```

### 5.2 GPX 解析器

```cpp
class GPXParser : public IRouteParser {
public:
    struct Result {
        Route route;
        QList<TrackPoint> trackPoints;
        ImportReport report;
    };
    
    Result parse(const QString& filePath) override {
        Result result;
        
        QFile file(filePath);
        if (!file.open(QIODevice::ReadOnly)) {
            result.report.addError("文件无法打开");
            return result;
        }
        
        QXmlStreamReader xml(&file);
        QStack<QString> tagStack;
        Waypoint currentWpt;
        TrackPoint currentTrkpt;
        bool inTrk = false;
        QString trkName;
        QDateTime lastTime;
        
        while (!xml.atEnd()) {
            xml.readNext();
            
            if (xml.isStartElement()) {
                QString name = xml.name().toString();
                tagStack.push(name);
                
                if (name == "metadata") {
                    parseMetadata(xml, result.route);
                } else if (name == "wpt") {
                    currentWpt = Waypoint();
                    QGeoCoordinate coord(
                        xml.attributes().value("lat").toDouble(),
                        xml.attributes().value("lon").toDouble()
                    );
                    currentWpt.coord = coord;
                } else if (name == "trk") {
                    inTrk = true;
                } else if (name == "rte") {
                    // 路线点
                } else if (name == "trkpt" || name == "rtept") {
                    currentTrkpt = TrackPoint();
                    currentTrkpt.coord = QGeoCoordinate(
                        xml.attributes().value("lat").toDouble(),
                        xml.attributes().value("lon").toDouble()
                    );
                }
            } else if (xml.isEndElement()) {
                QString name = xml.name().toString();
                
                if (name == "wpt") {
                    result.route.waypoints.append(currentWpt);
                } else if (name == "trkpt" || name == "rtept") {
                    if (inTrk) {
                        result.trackPoints.append(currentTrkpt);
                    }
                } else if (name == "trk") {
                    inTrk = false;
                }
                
                if (!tagStack.isEmpty()) {
                    tagStack.pop();
                }
            } else if (xml.isCharacters() && !xml.isWhitespace()) {
                QString text = xml.text().toString().trimmed();
                if (text.isEmpty()) continue;
                
                QString topTag = tagStack.isEmpty() ? "" : tagStack.top();
                
                // 路径中的字段处理
                if (tagStack.size() >= 2) {
                    QString parent = tagStack.at(tagStack.size() - 2);
                    handleText(parent, topTag, text, 
                              &currentWpt, &currentTrkpt, &result.route);
                }
            }
        }
        
        if (xml.hasError()) {
            result.report.addWarning("XML 解析错误：" + xml.errorString());
        }
        
        return result;
    }
    
private:
    void handleText(const QString& parent, const QString& tag, 
                    const QString& text,
                    Waypoint* wpt, TrackPoint* trkpt, Route* route) {
        if (parent == "metadata") {
            if (tag == "name") route->name = text;
            else if (tag == "desc") route->description = text;
        } else if (parent == "wpt") {
            if (tag == "name") wpt->name = text;
            else if (tag == "ele") wpt->elevation = text.toInt();
            else if (tag == "desc") wpt->description = text;
            else if (tag == "type") wpt->type = text;
        } else if (parent == "trkpt" || parent == "rtept") {
            if (tag == "ele") trkpt->elevation = text.toInt();
            else if (tag == "time") trkpt->time = QDateTime::fromString(text, Qt::ISODate);
        } else if (parent == "trk") {
            if (tag == "name") {/* track name */}
        }
    }
};
```

```cpp
public:

        QString currentPlacemarkDesc;
        QString currentStyleUrl;

        int currentEle = 0;

        QList<int> currentLineEles;
        
        while (!xml.atEnd()) {
            xml.readNext();
            
            if (xml.isStartElement()) {
                QString name = xml.name().toString();
                
                if (name == "Placemark") {
                    currentPlacemarkName.clear();
                    currentPlacemarkDesc.clear();
                    currentStyleUrl.clear();
                    currentCoord = QGeoCoordinate();
                    currentLineCoords.clear();
                } else if (name == "Point") {
                    currentGeomType = "Point";
                } else if (name == "LineString") {
                    currentGeomType = "LineString";
                } else if (name == "coordinates") {
                    QString coordText = xml.readElementText().trimmed();
                    auto points = parseCoordinates(coordText);
                    
                    if (currentGeomType == "Point" && !points.isEmpty()) {
                        currentCoord = points.first();
                    } else if (currentGeomType == "LineString") {
                        currentLineCoords = points;
                    }
                } else if (name == "name") {
                    if (currentGeomType.isEmpty()) {
                        // 文档级 name
                        result.route.name = xml.readElementText();
                    } else {
                        currentPlacemarkName = xml.readElementText();
                    }
                } else if (name == "description") {
                    currentPlacemarkDesc = xml.readElementText();
                } else if (name == "styleUrl") {
                    currentStyleUrl = xml.readElementText();
                }
            } else if (xml.isEndElement()) {
                QString name = xml.name().toString();
                
                if (name == "Placemark") {
                    if (currentGeomType == "Point" && currentCoord.isValid()) {
                        Waypoint wpt;
                        wpt.name = currentPlacemarkName;
                        wpt.coord = currentCoord;
                        wpt.description = currentPlacemarkDesc;
                        wpt.type = inferWaypointType(currentStyleUrl);
                        result.route.waypoints.append(wpt);
                    } else if (currentGeomType == "LineString" && 
                              !currentLineCoords.isEmpty()) {
                        for (const auto& coord : currentLineCoords) {
                            TrackPoint tp;
                            tp.coord = coord;
                            result.trackPoints.append(tp);
                        }
                    }
                    currentGeomType.clear();
                }
            }
        }
        
        return result;
    }
    
private:
    QString extractFromKmz(const QString& kmzPath, Result& result) {
        // 使用 QuaZip 或 minizip 解压
        QuaZip zip(kmzPath);
        if (!zip.open(QuaZip::mdUnzip)) {
            result.report.addError("KMZ 打开失败");
            return QString();
        }
        
        // 找 doc.kml
        for (bool f = zip.goToFirstFile(); f; f = zip.goToNextFile()) {
            QString name = zip.getCurrentFileName();
            if (name.endsWith(".kml", Qt::CaseInsensitive)) {
                QuaZipFile file(&zip);
                file.open(QIODevice::ReadOnly);
                
                QString tmpPath = QStandardPaths::writableLocation(
                    QStandardPaths::TempLocation) + "/doc.kml";
                QFile out(tmpPath);
                out.open(QIODevice::WriteOnly);
                out.write(file.readAll());
                out.close();
                file.close();
                
                zip.close();
                return tmpPath;
            }
        }
        
        zip.close();
        return QString();
    }
    
    QList<QGeoCoordinate> parseCoordinates(const QString& text) {
        QList<QGeoCoordinate> coords;
        QStringList lines = text.split(QRegularExpression("\\s+"), 
                                       Qt::SkipEmptyParts);
        for (const QString& line : lines) {
            QStringList parts = line.split(',');
            if (parts.size() >= 2) {
                double lon = parts[0].toDouble();
                double lat = parts[1].toDouble();
                coords.append(QGeoCoordinate(lat, lon));
            }
        }
        return coords;
    }
```

```cpp
        // 常见列名:
        // lat/latitude/Latitude/LAT
        // lon/lng/longitude/Longitude/LON/LNG
        // ele/elevation/Elevation/Altitude/alt
        // time/timestamp/datetime/TIME
        // name/name/title
        
        int latIdx = findColumn(headers, {"lat", "latitude", "纬度"});
        int lonIdx = findColumn(headers, {"lon", "lng", "longitude", "经度"});
        int eleIdx = findColumn(headers, {"ele", "elevation", "altitude", "海拔"});
        int timeIdx = findColumn(headers, {"time", "timestamp", "datetime", "时间"});
        int nameIdx = findColumn(headers, {"name", "title", "名称"});
        
        // 3. 验证必要列
        if (latIdx < 0 || lonIdx < 0) {
            result.report.addError("CSV 必须包含经纬度列");
            return result;
        }
        
        // 4. 读取数据行
        while (!file.atEnd()) {
            QString line = QString::fromUtf8(file.readLine());
            QStringList cols = parseCSVLine(line);
            
            if (cols.size() < std::max(latIdx, lonIdx) + 1) continue;
            
            TrackPoint tp;
            tp.coord = QGeoCoordinate(
                cols[latIdx].toDouble(),
                cols[lonIdx].toDouble()
            );
            if (eleIdx >= 0 && eleIdx < cols.size()) {
                tp.elevation = cols[eleIdx].toInt();
            }
            if (timeIdx >= 0 && timeIdx < cols.size()) {
                tp.time = QDateTime::fromString(cols[timeIdx], Qt::ISODate);
            }
            if (tp.coord.isValid()) {
                result.trackPoints.append(tp);
            }
        }
        
        return result;
    }
```

```cpp
class RouteNormalizer {
public:
    // 将原始数据转为标准 Route
    static Route normalize(const QString& name, 
                           const QList<TrackPoint>& trackPoints,
                           const QList<Waypoint>& waypoints) {
        Route route;
        route.id = QUuid::createUuid().toString(QUuid::WithoutBraces);
        route.name = name;
        route.waypoints = waypoints;
        
        if (trackPoints.isEmpty()) {
            return route;
        }
        
        // 1. 计算距离（球面距离）
        double totalDist = 0;
        for (int i = 1; i < trackPoints.size(); ++i) {
            totalDist += trackPoints[i-1].coord.distanceTo(trackPoints[i].coord);
        }
        route.distance_km = totalDist / 1000.0;
        
        // 2. 计算爬升 / 下降
        int gain = 0, loss = 0;
        int maxEle = -99999, minEle = 99999;
        for (int i = 1; i < trackPoints.size(); ++i) {
            int dEle = trackPoints[i].elevation - trackPoints[i-1].elevation;
            // 滤波：避免 GPS 误差
            if (dEle > 3) gain += dEle;
            else if (dEle < -3) loss += -dEle;
            
            maxEle = std::max(maxEle, trackPoints[i].elevation);
            minEle = std::min(minEle, trackPoints[i].elevation);
        }
        route.elevation_gain_m = gain;
        route.elevation_loss_m = loss;
        route.max_altitude_m = maxEle;
        route.min_altitude_m = minEle;
        
        // 3. 计算预估时长
        // Naismith 法则：步行 5km/h，每 600m 爬升加 1h
        double hours = (route.distance_km / 5.0) + (gain / 600.0);
        route.duration_hours = hours;
        route.days_needed = std::ceil(hours / 8.0);  // 每天按 8h 算
        
        // 4. 自动评估难度
        route.difficulty = DifficultyCalculator::calculate(route);
        
        // 5. 推断地形
        route.terrain = inferTerrain(trackPoints);
        
        // 6. 设置起终点
        if (!trackPoints.isEmpty()) {
            route.trailhead = trackPoints.first().coord;
            route.trailend = trackPoints.last().coord;
        }
        
        route.created_at = QDateTime::currentDateTime();
        route.updated_at = route.created_at;
        route.user_imported = true;
        
        return route;
    }
    
    static QStringList inferTerrain(const QList<TrackPoint>& points) {
        QStringList terrain;
        if (points.size() < 2) return terrain;
        
        // 简单启发式
        // 1. 计算平均坡度
        double totalSlope = 0;
        for (int i = 1; i < points.size(); ++i) {
            double dist = points[i-1].coord.distanceTo(points[i].coord);
            int dEle = points[i].elevation - points[i-1].elevation;
            if (dist > 0) {
                totalSlope += std::abs(dEle / dist);
            }
        }
        double avgSlope = totalSlope / (points.size() - 1);
        
        if (avgSlope < 0.1) terrain << "缓坡";
        else if (avgSlope < 0.2) terrain << "中坡";
        else terrain << "陡坡";
        
        // 2. 看最高海拔
        if (!points.isEmpty()) {
            int maxEle = -99999;
            for (const auto& p : points) {
                maxEle = std::max(maxEle, p.elevation);
            }
            if (maxEle > 4500) terrain << "雪山";
            else if (maxEle > 3000) terrain << "高山";
            else if (maxEle > 1500) terrain << "中山";
            else if (maxEle > 500) terrain << "低山";
        }
        
        return terrain;
    }
};
```

```cpp
class DifficultyCalculator {
public:
    // 综合 5 维评分
    static int calculate(const Route& route) {
        // 地形评分
        int terrainScore = scoreTerrain(route);
        
        // 海拔评分
        int altitudeScore = scoreAltitude(route);
        
        // 距离评分
        int distanceScore = scoreDistance(route);
        
        // 爬升评分
        int elevationScore = scoreElevation(route);
        
        // 补给评分
        int supplyScore = scoreSupply(route);
        
        // 加权平均
        double total = 
            terrainScore * 0.30 +
            altitudeScore * 0.25 +
            distanceScore * 0.15 +
            elevationScore * 0.20 +
            supplyScore * 0.10;
        
        return std::clamp((int)std::round(total), 1, 5);
    }
    
private:
    static int scoreTerrain(const Route& route) {
        // 简化：基于难度关键词
        if (route.terrain.contains("雪山")) return 5;
        if (route.terrain.contains("高山")) return 4;
        if (route.terrain.contains("陡坡")) return 3;
        if (route.terrain.contains("中坡")) return 2;
        return 1;
    }
    
    static int scoreAltitude(const Route& route) {
        if (route.max_altitude_m >= 4500) return 5;
        if (route.max_altitude_m >= 3000) return 4;
        if (route.max_altitude_m >= 1500) return 3;
        if (route.max_altitude_m >= 500) return 2;
        return 1;
    }
    
    static int scoreDistance(const Route& route) {
        if (route.distance_km >= 40) return 5;
        if (route.distance_km >= 20) return 4;
        if (route.distance_km >= 10) return 3;
        if (route.distance_km >= 5) return 2;
        return 1;
    }
    
    static int scoreElevation(const Route& route) {
        if (route.elevation_gain_m >= 3000) return 5;
        if (route.elevation_gain_m >= 1500) return 4;
        if (route.elevation_gain_m >= 500) return 3;
        if (route.elevation_gain_m >= 100) return 2;
        return 1;
    }
    
    static int scoreSupply(const Route& route) {
        // 补给点越少，分数越高（难度大）
        int n = route.supply_points.size();
        if (n == 0) return 5;
        if (n == 1) return 4;
        if (n == 2) return 3;
        if (n <= 4) return 2;
        return 1;
    }
};
```

```cpp
void ImportManager::processTask(ImportTask task) {
    // 1. 读取
    QFile file(task.inputPath);

        return;

    auto parser = selectParser(fmt);
    if (!parser) {
        emit importFailed("不支持的格式");
        return;

    QString tmpPath;
    if (fmt == FormatDetector::KMZ) {
        // 写到临时文件
        tmpPath = QStandardPaths::writableLocation(
            QStandardPaths::TempLocation) + "/import.kmz";
        QFile tmp(tmpPath);
        tmp.open(QIODevice::WriteOnly);
        tmp.write(task.rawData);
    } else {
        tmpPath = task.inputPath;
    }
    
    auto result = parser->parse(tmpPath);
    
    emit importProgress(70);
    
    // 4. 规范化
    Route route = RouteNormalizer::normalize(
        result.route.name.isEmpty() ? 
            QFileInfo(task.inputPath).baseName() : 
            result.route.name,
        result.trackPoints,
        result.route.waypoints
    );
    
    // 合并其他字段
    route.description = result.route.description;
    route.water_sources = result.route.water_sources;
    route.supply_points = result.route.supply_points;
    route.dangers = result.route.dangers;
    route.format_source = formatToString(fmt);
    route.source = task.inputPath;
    
    // 5. 增强
    DangerDetector::detect(route);
    
    emit importProgress(90);
    
    // 6. 发送预览
```

```cpp
class RouteValidator {
public:
    struct ValidationResult {
        bool valid;

    static ValidationResult validate(const Route& route) {
        ValidationResult result;
        result.valid = true;
        
        // 必填字段
        if (route.name.isEmpty()) {
            result.errors << "路线名称不能为空";
            result.valid = false;
        }
        
        if (route.distance_km < 0.1) {
            result.warnings << "距离过短（< 0.1km），请检查";
        }
        
        if (route.max_altitude_m < -500 || route.max_altitude_m > 9000) {

                              + QString::number(route.max_altitude_m) + "m）";
        }
        
        // 范围检查
        if (route.difficulty < 1 || route.difficulty > 5) {
            result.warnings << "难度值异常";
        }
        
        // GPS 范围（中国境内）
        for (const auto& wpt : route.waypoints) {
            if (!isInChina(wpt.coord)) {
                result.warnings << "路点 " + wpt.name + " 不在中国境内";
            }
        }
        
        // 建议
        if (route.waypoints.size() < 3) {
            result.suggestions << "建议添加更多路点（起点、终点、关键点）";
        }
        if (route.dangers.isEmpty()) {
            result.suggestions << "建议补充危险点信息";
        }
        if (route.supply_points.isEmpty()) {
            result.suggestions << "建议补充补给点信息";
        }
        if (route.description.length() < 50) {
            result.suggestions << "建议添加更详细的描述";
        }
        
        return result;
    }
    
    static bool isInChina(const QGeoCoordinate& coord) {
        return coord.latitude() >= 18.0 && coord.latitude() <= 53.5 &&
               coord.longitude() >= 73.0 && coord.longitude() <= 135.0;
    }
```

### 10.2 存储优化

```cpp
class RouteStorage {
public:
    // 1. 轨迹点压缩
    static QByteArray compressTrackPoints(const QList<TrackPoint>& points) {
        // Douglas-Peucker 算法抽稀
        auto simplified = douglasPeucker(points, 5.0);  // 5m 容差
        return serialize(simplified);
    }
    
    // 2. 抽稀算法（保留形状，减少点）
    static QList<TrackPoint> douglasPeucker(
        const QList<TrackPoint>& points, double tolerance) {
        if (points.size() < 3) return points;
        
        // 找最大距离
        double maxDist = 0;
        int maxIdx = 0;
        for (int i = 1; i < points.size() - 1; ++i) {
            double d = perpendicularDistance(
                points[i].coord,
                points.first().coord,
                points.last().coord
            );
            if (d > maxDist) {
                maxDist = d;
                maxIdx = i;
            }
        }
        
        if (maxDist > tolerance) {
            auto left = douglasPeucker(
                points.mid(0, maxIdx + 1), tolerance);
            auto right = douglasPeucker(
                points.mid(maxIdx), tolerance);
            
            return left.mid(0, left.size() - 1) + right;
        } else {
            return {points.first(), points.last()};
        }
    }
};
```

### 10.3 轨迹抽稀策略

- **原始轨迹**：用于精确导航
- **简化轨迹**（抽稀）：用于地图显示
- **概览轨迹**（重抽稀）：用于列表卡片

抽稀比例建议：
- 详细：每 5m 一点
- 简化：每 30m 一点
- 概览：每 100m 一点

## 十一、与在线数据的关系

### 11.1 两种模式

#### 模式 A：纯离线
- 仅导入用户自带数据
- App 内不下载官方路线
- **优点**：完全无网络依赖
- **缺点**：内容有限

#### 模式 B：在线 + 离线（推荐）
- 首次启动下载官方精选路线包
- 用户可继续导入自定义路线
- 已下载的完全离线可用
- **优点**：内容丰富 + 完全离线
- **缺点**：首次需联网

### 11.2 推荐方案

```
1. App 安装后引导用户选择：
   - 仅离线模式
   - 下载精选路线包（推荐）

2. 路线管理分两栏：
   - [内置] - 官方精选
   - [我的] - 用户导入

3. 用户导入的路线：
   - 完全本地存储
   - 不上传服务器（隐私保护）
   - 可选分享

4. 官方路线：
   - 下载时含完整数据
   - 下载后可删除
   - 不与用户数据混合
```

### 11.3 数据同步（可选）

如果用户开启云同步：
- 同步用户导入的路线（不上传轨迹详细数据）
- 仅同步：路线名、难度、简评、照片缩略图
- 详细轨迹保留本地

## 附录 A：格式详解

### A.1 GPX 1.1 标准字段

必选：
- `<wpt lat lon>` - 路点
- `<trk><trkseg><trkpt lat lon></trkpt></trkseg></trk>` - 轨迹

可选：
- `<metadata><name/desc/author/time/bounds>` - 元数据
- `<rte><rtept>` - 路线（不同于轨迹）
- `<ele>` - 海拔
- `<time>` - 时间
- `<extensions>` - 扩展（厂商自定义）

### A.2 KML 2.2 关键元素

- `<Placemark>` - 地标
- `<Point>` - 点
- `<LineString>` - 线
- `<Polygon>` - 多边形
- `<Style>` / `<StyleUrl>` - 样式
- `<Folder>` - 文件夹
- `<NetworkLink>` - 网络链接

### A.3 关键开源库

| 库 | 协议 | 用途 |
|---|---|---|
| **QXmlStreamReader** | Qt | XML 解析 |
| **quazip** | LGPL | ZIP 解压（KMZ） |
| **libfit** | Apache 2 | FIT 解析 |
| **nlohmann/json** | MIT | JSON 解析 |
| **Tesseract** | Apache 2 | OCR |
