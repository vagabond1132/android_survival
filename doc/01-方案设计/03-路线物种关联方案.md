## 一、需求背景

### 1.1 用户痛点

| 场景 | 痛点 |
|---|---|
| **出发前** | 不知道路上会遇到什么动植物，无法针对性准备 |
| **途中** | 看到植物不知是否有毒 / 可食 |
| **遇见动物** | 不认识，无法判断危险 |
| **食用野菜** | 凭印象采摘，中毒事件频发 |
| **遇见毒蛇** | 反应迟缓，错失急救时机 |
| **携带装备** | 不知是否需要防蛇装备 |
| **季节出行** | 不了解季节性风险（如毒蛇活跃期） |

### 1.2 典型场景

#### 场景 1：用户计划去武功山徒步
- 系统提示："该路线海拔 500-1918m，预计可见到："
  - 植物：杜鹃花（5-6月盛开）、芒草、银杏
  - 动物：野猪、华南兔、画眉
  - 危险：五步蛇（夏秋活跃）、胡蜂、蜱虫
  - 提示：建议携带蛇毒吸附器、防虫喷雾

#### 场景 2：用户在西双版纳热带雨林
- 系统提示："当前路线位于热带雨林，注意："
  - 植物：见血封喉、曼陀罗、毒蘑菇
  - 动物：眼镜王蛇、烙铁头、蚂蟥
  - 危险：毒蛇咬伤、虫媒疾病（登革热）
  - 提示：建议穿长裤高帮鞋、备好抗蛇毒血清卡

#### 场景 3：用户在云南香格里拉高山草甸
- 系统提示："当前海拔 3500m+："  
  - 植物：冬虫夏草、雪莲、红景天
  - 动物：藏羚羊、旱獭、雪豹（罕见）
  - 危险：高原反应、强烈紫外线
  - 提示：建议缓慢上升、戴遮阳帽

### 1.3 核心价值

1. **提升安全性**：提前知道危险动植物
2. **学习机会**：认识新物种
3. **决策辅助**：决定装备 / 时机 / 路线
4. **应急准备**：知道可能遇到的急症
5. **增加趣味**：让徒步更有探索感

## 二、核心设计思路

### 2.1 总体架构

```
┌────────────────────────────────────────────┐
│            路线数据 (Route)                 │
│  - 坐标 (lat/lon)                          │
│  - 海拔 (min/max)                          │
│  - 时间 (月份 / 时长)                      │
│  - 地区 (省 / 市 / 山系)                    │
│  - 地形 (山脊/河谷/草甸/...)                │
└────────────────────────────────────────────┘
                  ↓
┌────────────────────────────────────────────┐
│         匹配引擎 (Matcher)                 │
│  1. 地理匹配 (经纬度范围)                   │
│  2. 海拔匹配 (物种适宜海拔)                 │
│  3. 生境匹配 (物种栖息地)                   │
│  4. 季节匹配 (物候期)                       │
│  5. 综合评分 + 排序                         │
└────────────────────────────────────────────┘
                  ↓
┌────────────────────────────────────────────┐
│         结果展示 (UI)                      │
│  - 物种卡片                                 │
│  - 风险等级                                 │
│  - 防护建议                                 │
│  - 跳转识别                                 │
└────────────────────────────────────────────┘
```

### 2.2 关键设计原则

| 原则 | 说明 |
|---|---|
| **离线优先** | 完全在本地运行，无网络依赖 |
| **多维匹配** | 地理 + 海拔 + 生境 + 季节综合 |
| **保守推荐** | 不确定的宁可少提示，不可错提示 |
| **风险优先** | 危险物种置顶 |
| **可解释** | 每个推荐说明"为什么推荐" |
| **可学习** | 用户标记"未见到"可降低评分 |

### 2.3 数据流

```
导入路线
  ↓
提取路线特征
  - 坐标范围 bbox
  - 海拔区间
  - 估算月份（如果已知）
  - 地形类型
  ↓
构建匹配查询
  ↓
查询本地动植物数据库
  - 按地理过滤
  - 按海拔过滤
  - 按生境过滤
  - 按季节过滤
  ↓
计算匹配分数
  ↓
排序 + 分类
  - 危险物种
  - 常见物种
  - 季节性物种
  ↓
展示
```

## 四、匹配算法

### 4.1 综合匹配评分

```cpp
class SpeciesRouteMatcher {
public:
    struct MatchResult {
        Species species;
        double score;              // 0-100
        QList<MatchReason> reasons;
        int riskLevel;             // 0-5
        bool isHighConfidence;     // 高置信度推荐
    };
    
    struct MatchReason {
        QString type;              // 地理/海拔/生境/季节
        QString description;
        double weight;
    };
    
    QList<MatchResult> match(const Route& route, 
                              const QDateTime& planDate = QDateTime()) {
        QList<MatchResult> results;
        
        // 1. 预过滤：地理 + 海拔
        auto candidates = preFilter(route);
        
        for (const auto& species : candidates) {
            MatchResult result;
            result.species = species;
            result.riskLevel = species.dangerLevel;
            
            // 2. 地理评分（40%）
            double geoScore = scoreGeo(species, route);
            
            // 3. 海拔评分（25%）
            double eleScore = scoreElevation(species, route);
            
            // 4. 生境评分（20%）
            double habScore = scoreHabitat(species, route);
            
            // 5. 季节评分（15%）
            double seasonScore = scoreSeason(species, route, planDate);
            
            result.score = geoScore * 0.40 + 
                          eleScore * 0.25 + 
                          habScore * 0.20 + 
                          seasonScore * 0.15;
            
            // 6. 高置信度判定
            result.isHighConfidence = 
                geoScore >= 80 && eleScore >= 70 && 
                habScore >= 60 && seasonScore >= 50;
            
            // 7. 构建匹配原因
            if (geoScore >= 80) {
                result.reasons << {"地理", 
                    QString("分布于该区域（%1）").arg(species.provinces.join("、")), 
                    geoScore};
            }
            if (eleScore >= 70) {
                result.reasons << {"海拔", 
                    QString("适宜海拔 %1-%2m，路线海拔 %3-%4m")
                        .arg(species.elevationMin).arg(species.elevationMax)
                        .arg(route.min_altitude_m).arg(route.max_altitude_m),
                    eleScore};
            }
            if (habScore >= 60) {
                result.reasons << {"生境", 
                    QString("常见于%1").arg(species.habitats.join("、")), 
                    habScore};
            }
            if (seasonScore >= 50) {
                result.reasons << {"季节", 
                    QString("该季节活跃 / 可见"), seasonScore};
            }
            
            // 8. 风险加权（危险物种略微提升，确保置顶）
            if (species.dangerLevel >= 4) {
                result.score *= 1.1;
            }
            
            results.append(result);
        }
        
        // 排序：风险 > 分数
        std::sort(results.begin(), results.end(), 
                  [](const MatchResult& a, const MatchResult& b) {
            if (a.riskLevel != b.riskLevel) {
                return a.riskLevel > b.riskLevel;
            }
            return a.score > b.score;
        });
        
        return results;
    }
    
private:
    QList<Species> preFilter(const Route& route) {
        // 快速过滤：地理 + 海拔 50% 重叠
        QList<Species> result;
        for (const auto& sp : allSpecies) {
            // 地理范围重叠
            if (!geoOverlaps(sp.geoRange, route.geoBBox())) continue;
            
            // 海拔范围重叠
            int routeMin = route.min_altitude_m;
            int routeMax = route.max_altitude_m;
            int overlapMin = std::max(sp.elevationMin, routeMin);
            int overlapMax = std::min(sp.elevationMax, routeMax);
            if (overlapMax < overlapMin - 200) continue;  // 容差 200m
            
            result.append(sp);
        }
        return result;
    }
    
    double scoreGeo(const Species& sp, const Route& route) {
        // 计算物种分布中心与路线中心的距离
        double speciesCenterLat = (sp.geoRange.topLeft().latitude() + 
                                    sp.geoRange.bottomRight().latitude()) / 2;
        double speciesCenterLon = (sp.geoRange.topLeft().longitude() + 
                                    sp.geoRange.bottomRight().longitude()) / 2;
        double routeCenterLat = route.geoBBox().center().latitude();
        double routeCenterLon = route.geoBBox().center().longitude();
        
        double dist = haversineDistance(
            speciesCenterLat, speciesCenterLon,
            routeCenterLat, routeCenterLon);
        
        if (dist < 50) return 100;       // 50km 内满分
        if (dist < 100) return 90;
        if (dist < 200) return 80;
        if (dist < 500) return 60;
        if (dist < 1000) return 40;
        return 20;
    }
    
    double scoreElevation(const Species& sp, const Route& route) {
        int spMin = sp.elevationMin, spMax = sp.elevationMax;
        int rMin = route.min_altitude_m, rMax = route.max_altitude_m;
        
        // 重叠比例
        int overlapMin = std::max(spMin, rMin);
        int overlapMax = std::min(spMax, rMax);
        
        if (overlapMax < overlapMin) {
            // 无重叠，看差距
            int gap = overlapMin - overlapMax;
            if (gap < 200) return 70;   // 接近
            if (gap < 500) return 50;
            if (gap < 1000) return 30;
            return 10;
        }
        
        int overlap = overlapMax - overlapMin;
        int spRange = spMax - spMin;
        int rRange = rMax - rMin;
        
        // 重叠占物种适宜海拔的比例
        double ratio = (double)overlap / std::max(spRange, 1);
        return std::min(100.0, 50.0 + ratio * 50.0);
    }
    
    double scoreHabitat(const Species& sp, const Route& route) {
        // 生境关键词匹配
        QStringList routeTerrains = route.terrain;
        QStringList speciesHabitats = sp.habitats;
        
        int matches = 0;
        for (const QString& h : speciesHabitats) {
            for (const QString& t : routeTerrains) {
                if (h.contains(t) || t.contains(h)) {
                    matches++;
                }
            }
        }
        
        if (matches == 0) return 30;  // 都不匹配
        return std::min(100.0, 30.0 + matches * 25.0);
    }
    
    double scoreSeason(const Species& sp, const Route& route, 
                       const QDateTime& planDate) {
        int month = planDate.isValid() ? planDate.date().month() 
                                        : QDate::currentDate().month();
        
        // 物候匹配
        if (sp.phenology.activeMonths.contains(QString::number(month))) {
            return 100;
        }
        if (sp.phenology.floweringMonths.contains(QString::number(month))) {
            return 90;
        }
        if (sp.phenology.fruitingMonths.contains(QString::number(month))) {
            return 90;
        }
        
        // 相邻月份
        int prev = month == 1 ? 12 : month - 1;
        int next = month == 12 ? 1 : month + 1;
        if (sp.phenology.activeMonths.contains(QString::number(prev)) ||
            sp.phenology.activeMonths.contains(QString::number(next))) {
            return 70;
        }
        
        // 冬眠 / 不活跃期
        if (sp.phenology.hibernationMonths.contains(QString::number(month))) {
            return 20;
        }
        
        return 50;  // 无明确数据
    }
};
```

### 4.3 路线特性预计算

为避免每次都重新计算，提取路线特性一次：

```cpp
class RouteFeatureExtractor {
public:
    RouteFeatures extract(const Route& route) {
        RouteFeatures f;
        
        // 1. 地理边界
        QGeoCoordinate topLeft(90, 180);
        QGeoCoordinate bottomRight(-90, -180);
        for (const auto& tp : route.track_points) {
            topLeft.setLatitude(std::min(topLeft.latitude(), tp.coord.latitude()));
            topLeft.setLongitude(std::min(topLeft.longitude(), tp.coord.longitude()));
            bottomRight.setLatitude(std::max(bottomRight.latitude(), tp.coord.latitude()));
            bottomRight.setLongitude(std::max(bottomRight.longitude(), tp.coord.longitude()));
        }
        f.bbox = QGeoRectangle(topLeft, bottomRight);
        
        // 2. 海拔
        if (!route.track_points.isEmpty()) {
            f.elevationMin = route.min_altitude_m;
            f.elevationMax = route.max_altitude_m;
        }
        
        // 3. 行政区（基于经纬度反查）
        f.province = reverseGeoProvince(f.bbox.center());
        f.city = reverseGeoCity(f.bbox.center());
        
        // 4. 地形分类
        f.terrainTypes = route.terrain;
        
        // 5. 植被带
        f.vegetationZone = inferVegetationZone(f);
        
        // 6. 气候
        f.climate = inferClimate(f);
        
        return f;
    }
    
    QString inferVegetationZone(const RouteFeatures& f) {
        int midEle = (f.elevationMin + f.elevationMax) / 2;
        double lat = f.bbox.center().latitude();
        
        // 简化
        if (midEle > 4500) return "高山冰雪";
        if (midEle > 3500) return "高山草甸";
        if (midEle > 2500) return "亚高山针叶林";
        if (midEle > 1500) return "中山针阔混交林";
        if (midEle > 500) return "低山常绿阔叶林";
        return "平原/丘陵";
    }
};
```

### 7.2 季节性规则

```cpp
class SeasonalRuleEngine {
public:
    struct SeasonalContext {
        int month;
        double latitude;
        int elevation;
        QString climateZone;
    };
    
    // 判断当前是否某物种活跃期
    bool isActive(const Species& sp, const SeasonalContext& ctx) {
        // 1. 直接匹配
        if (sp.phenology.activeMonths.contains(
                QString::number(ctx.month))) {
            return true;
        }
        
        // 2. 基于区域 + 季节推断
        if (sp.category == "snake") {
            return inferSnakeActive(sp, ctx);
        }
        if (sp.category == "insect") {
            return inferInsectActive(sp, ctx);
        }
        if (sp.category == "plant") {
            return inferPlantFlowering(sp, ctx);
        }
        
        return true;  // 默认假设可见
    }
    
private:
    bool inferSnakeActive(const Species& sp, const SeasonalContext& ctx) {
        // 蛇类在 10°C 以下冬眠
        // 中国：
        // 北方：5-9 月活跃
        // 南方：4-11 月活跃
        // 海南：全年活跃
        
        bool isSouth = ctx.latitude < 30;
        bool isTropical = ctx.latitude < 23 && ctx.elevation < 500;
        
        if (isTropical) return true;  // 热带全年
        
        if (isSouth) {
            return ctx.month >= 4 && ctx.month <= 11;
        } else {
            return ctx.month >= 5 && ctx.month <= 9;
        }
    }
    
    bool inferInsectActive(const Species& sp, const SeasonalContext& ctx) {
        // 蜱虫：4-10 月活跃
        if (sp.id.contains("tick")) {
            return ctx.month >= 4 && ctx.month <= 10;
        }
        // 蚂蟥：5-9 月最活跃
        if (sp.id.contains("leech")) {
            return ctx.month >= 5 && ctx.month <= 9;
        }
        // 蜂类：7-10 月活跃
        if (sp.id.contains("wasp") || sp.id.contains("bee")) {
            return ctx.month >= 7 && ctx.month <= 10;
        }
        return true;
    }
    
    bool inferPlantFlowering(const Species& sp, const SeasonalContext& ctx) {
        if (sp.phenology.floweringMonths.isEmpty()) {
            return true;  // 未知
        }
        return sp.phenology.floweringMonths.contains(
            QString::number(ctx.month));
    }
};
```

```cpp
class EnhancedRecognizer {
public:
    RecognitionResult recognizeWithRouteContext(
        const QImage& image, 
        const Route& currentRoute) {
        
        // 1. 基础识别
        auto baseResult = baseRecognizer_.recognize(image);
        
        // 2. 路线上下文过滤
        // 只考虑该路线范围内可能出现的物种
        QList<QString> routeSpeciesIds;
        for (const auto& sp : matcher_.matchRoute(currentRoute.id)) {
            routeSpeciesIds.append(sp.speciesId);
        }
        
        // 3. 加权评分
        for (auto& alt : baseResult.alternatives) {
            if (routeSpeciesIds.contains(alt.speciesId)) {
                alt.confidence *= 1.3;  // 路线范围内加分
            } else {
                alt.confidence *= 0.5;  // 路线范围外减分
            }
        }
        
        // 4. 重新排序
        std::sort(baseResult.alternatives.begin(), 
                  baseResult.alternatives.end(),
                  [](const auto& a, const auto& b) {
            return a.confidence > b.confidence;
        });
        
        return baseResult;
    }
};
```
