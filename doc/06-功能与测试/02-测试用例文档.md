## 一、测试策略

### 1.1 测试金字塔

```
            ┌─────────┐
            │  E2E    │  5%  - 关键路径
            ├─────────┤
            │  集成   │  25% - 模块协同
            ├─────────┤
            │  单元   │  70% - 函数 / 类
            └─────────┘
```

### 1.2 测试覆盖目标

| 模块 | 目标覆盖率 |
|---|---|
| 急救核心 | 90% |
| SOS / 紧急 | 95% |
| 危险物种 | 85% |
| 拍照识别 | 80% |
| 生存技能 | 80% |
| 路线 | 75% |
| 应急储备 | 85% |
| 平台适配 | 70% |
| **总体** | **80%** |

### 1.3 测试环境

- **开发**：开发机 + 模拟器
- **测试**：测试机矩阵（20+ 设备）
- **预生产**：β 用户
- **生产**：真实用户 + 监控

### 1.4 测试工具

| 类型 | 工具 |
|---|---|
| 单元测试 | Qt Test + Google Test |
| 集成测试 | Qt Test + QSignalSpy |
| UI 测试 | Qt Quick Test |
| 性能测试 | Android Profiler + Perfetto |
| 安全测试 | MobSF + 手动审查 |

## 二、单元测试用例

### 2.1 FirstAidService 急救服务

#### TC-FA-001: 加载初始数据
- **前置**：数据库已打开
- **步骤**：
  1. 调用 `loadInitialData()`
  2. 检查加载条数
- **预期**：
  - 至少加载 8 条核心急救
  - `totalCount()` > 0
  - 无错误日志
- **覆盖率**：正常路径

#### TC-FA-002: 按分类查询
- **前置**：数据已加载
- **步骤**：
  1. 调用 `getByCategory(Category::Critical)`
  2. 调用 `getByCategory(Category::Trauma)`
  3. 调用 `getByCategory(Category::Environment)`
  4. 调用 `getByCategory(Category::Poison)`
- **预期**：
  - 各类别返回对应条目
  - 互斥（无重叠）
  - 不返回空数组（除非该类无数据）

#### TC-FA-003: 按 ID 获取
- **步骤**：
  1. 获取所有条目 ID
  2. 随机选 3 个 ID 调用 `getById()`
  3. 传入不存在的 ID
- **预期**：
  - 存在的 ID 返回完整数据
  - 不存在的 ID 返回空 map
  - 字段非空（标题、紧急度等）

#### TC-FA-004: 紧急度筛选
- **步骤**：
  1. 调用 `getByUrgency(Urgency::Critical)` 5 次
  2. 调用 `getCritical()`
- **预期**：
  - `getCritical` 返回紧急度 >= 4 的所有
  - 紧急度数字正确

#### TC-FA-005: 关键词搜索
- **步骤**：
  1. 搜索 "出血"
  2. 搜索 "snake"
  3. 搜索 "高反"
  4. 搜索空字符串
  5. 搜索不存在的关键词
- **预期**：
  - 匹配标题、描述中的关键词
  - 大小写不敏感
  - 空字符串返回空数组
  - 不存在的关键词返回空数组

#### TC-FA-006: 决策树根节点
- **步骤**：
  1. 传入有效 entryId
  2. 传入无效 entryId
- **预期**：
  - 有效 ID 返回根节点
  - 包含 question、options
  - 无效 ID 返回空 map

#### TC-FA-007: 决策树节点查询
- **步骤**：
  1. 获取根节点
  2. 通过 nodeId 查询子节点
- **预期**：
  - 节点包含完整字段
  - 终止节点 isTerminal=true

#### TC-FA-008: 急救包模板
- **步骤**：
  1. 调用 `getKitTemplates()`
  2. 选择一个模板调用 `getKitTemplate(scenario)`
- **预期**：
  - 返回所有模板
  - 模板包含 name、items、totalWeightG
  - 至少 3 个模板

#### TC-FA-009: 关联物种
- **步骤**：
  1. 调用 `getRelatedSpecies("firstaid_snake_bite")`
- **预期**：
  - 返回相关蛇类 ID 列表
  - 包含至少 1 个

#### TC-FA-010: 数据完整性
- **步骤**：
  1. 加载所有数据
  2. 检查每条急救必填字段
- **预期**：
  - title 非空
  - category 在枚举范围
  - urgency 在 1-5
  - criticalActions 非空（紧急度 >= 4）
