## 变更公告：本轮 (2026-10-16 · 第十二轮 代码梳理 + 文档对账)

  切到线上真正打进 APK 的 `src/lifesaver`/`src/preparation`。
- **新增 4 个测试套件**:`test_asset_loader`(JSON 条目数对账)、`test_settings_store`、
  `test_checklist_service`、`test_map_service`(此前 45 个 Q_INVOKABLE 零覆盖)。
  > ⚠️ 2026-10-22 更正: 这条"对账"当时**从没真的跑过** —— `test_allDataFilesParse_data` /
  > `test_recordsCarryId_data` 没有配对的 `test_*` 函数, QTest 把 `*_data` 当数据提供者,
  > 找不到宿主就静默跳过。7 个 service 的 `test_load*_data` 同一批哑火。8 个槽位改名复活后,
  > 套件从"看着全绿"变成真跑, 当场暴露 `checklists.json` 没有 `id` 字段(服务层用
  > `scenario` 当主键, 属设计, 断言已按文件分主键字段)。
- **桌面单测镜像**:`Dockerfile.hosttests` + `docker-compose.yml` 的 `unit-test` service
  (原 APK 镜像的桌面 Qt 缺 `qtpositioning`,任何碰 `QGeoCoordinate` 的测试都编不过)。
- **死代码归档**:`.bak_deadcode_20261016/` 收 49 个文件/6,774 行(重构遗留的 firstaid/emergency
  旧副本、未接线的 Recognition*、零引用的 `DecisionEngine`、未注册的 QML 页面与组件)。
- **QML 唯一运行期告警修复**:`HomePage.qml:226` 退出时 `firstAidService` 已析构导致
  `Cannot read property 'totalEntries' of null`(run.txt 整份日志里唯一一条 QML warning),加 null 守卫。

  (此前桌面构建报 `QJniObject is incomplete`,而非 Android 分支仍要 `new AndroidPlatform()` 桩)。
- **文档对账**:所有统计数字改为脚本重新实测(见下表),并修掉 `H:\AI_Claude\work_dir\app` 这类

> **这一节的数字是量出来的, 不是抄的** —— 复现命令(都在 `app/` 下跑):
>
> ```bash
> find src -name '*.cpp' -o -name '*.h' -o -name '*.inl' | xargs wc -l        # C++ 文件数与行数
> find qml -name '*.qml' | xargs wc -l                                        # QML 行数
> grep -rE '^\s*Q_INVOKABLE\b' src --include=*.h | wc -l                       # 330
> grep -rn 'Q_INVOKABLE' src --include=*.h --include=*.cpp | wc -l             # 335 —— 含注释里的提及
> grep -rn 'Q_INVOKABLE' src --include=*.h --include=*.cpp \
>   | grep -vE ':\s*(//|\*)' | wc -l                                          # 330 —— 去掉注释后的口径
> # 测试函数数: 必须只数 `private slots:` 段里的, 且排掉 48 个生命周期槽位
> awk 'FNR==1{sec=""} /^[[:space:]]*(private|protected|public)[[:space:]]+slots[[:space:]]*:/{sec="slots";next}
>      /^[[:space:]]*(private|protected|public)[[:space:]]*:/{sec=""}
>      sec=="slots" && /^[[:space:]]+void[[:space:]]+[A-Za-z_][A-Za-z0-9_]*\(\)/{n++} END{print n}' \
>   tests/unit/*.cpp                                                            # 394 = 346 测试函数 + 48 生命周期
> ```
>
> 上一版这里写"262 个 `test_*` 用例"是用 `test_` 前缀数的, 而 `test_common_options.cpp`
> 整个文件一个 `test_` 前缀都没有 (槽位叫 `strip_* / plate_* / mpp_* / fit_*`),
> 所以那个数字系统性漏掉了一整个套件. 2026-10-22 任务 #88 查 `*_data` 孤儿槽时撞见的,
> 同一条教训: **门禁报 0 条要先用一个已知命中的样本反证脚本是活的.**
>
> 另一条同族的坑(2026-10-22 任务 #82 收尾时撞见): 用宽松的 `grep '^\s+void '` 数测试函数
