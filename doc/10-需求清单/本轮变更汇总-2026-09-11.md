## 1. 误判修正 (基础性问题)

### 1.1 R1 push 失效 (最关键误判)

**错误判断**: 之前我推断"Qt 6.5+ qmlcachegen 静态编译下, setContextProperty 在 rootContext 上的 property 在 QML 字节码里丢失", 改成 `qmlRegisterSingletonInstance` 修.

**事实** (17:01 logcat 验证): `qmlRegisterSingletonInstance` 在 QML import module 模式下**反而不工作** —— 报 `ReferenceError: firstAidService is not defined`.

**正确修法**:
- `setContextProperty` 一直工作 (main.cpp 的 `qmlRegisterSingletonInstance("OutdoorSurvival", 1, 0, "App", &theApp)` 正常, 因为 App 有 QML 端直接引用)
- 真 R1 是 `pageSignalTarget.target = null` 失连
- 已回滚: `src/core/ServiceRegistry.cpp` 用 `ctx->setContextProperty(...)` (14 service + 1 platform)

### 1.2 qmldir 目录式 import

**问题**: MapPage 用 `import "components/MapOverlay"`, 触发 `no such directory` (run.txt 17:03)

**根因**: 目录式 import 必须在该目录有 `qmldir` 文件声明每个 QML 类型

**修法**: 新建 2 个 `qmldir`:
- `qml/components/MapOverlay/qmldir`: 声明 DirectionCompassOverlay / MapRightButtonColumn / MapBottomSheet
- `qml/components/MapOverlay/tabs/qmldir`: 声明 RecordTab / NavigationTab / NearbyTab / SearchTab

### 1.3 ServiceRegistry 之前推断的"qmlcachegen 漏编 25 个 Page"

**错误判断**: 我推断 `qt_add_qml_module` 在 Qt 6.7 下只编 1 个 Page (HomePage)

**事实**: `build/release_arm64-v8a/.rcc/qmlcache/OutdoorSurvival_qml/pages/*.cpp` 有 26 个 Page 全部生成, `OutdoorSurvival/qmldir` 完整 26 个 Page 声明.

**误判根因**: 我读的 `build.txt` 是被裁剪的 196 行摘要日志, 不是完整 build log. 实际本地 `build/` 目录产物完整.
