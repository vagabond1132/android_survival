### 3.1 A. AssetLoader (资源路径统一)

**问题** (1): 11 个 service 用了 4 种候选路径风格。

**设计**:
```cpp
// src/core/AssetLoader.h
namespace outdoor {

class AssetLoader {
public:
    /** 加载只读 assets/data/<name>.json, 返回字节数组 */
    static QByteArray loadDataJson(const QString& name);
    
    /** 同上, 直接解析成 QJsonDocument */
    static std::optional<QJsonDocument> loadJson(const QString& name, QString* err = nullptr);
};

} // namespace
```

```cpp
// src/core/AssetLoader.cpp
#include "AssetLoader.h"
#include <QFile>
#include <QJsonDocument>
#include <QJsonParseError>

namespace outdoor {

static const QString kAssetsPrefix = ":/qt/qml/OutdoorSurvival/assets/data/";

QByteArray AssetLoader::loadDataJson(const QString& name) {
    QFile f(kAssetsPrefix + name);
    if (!f.open(QIODevice::ReadOnly)) {
        return {};
    }
    return f.readAll();
}

std::optional<QJsonDocument> AssetLoader::loadJson(const QString& name, QString* err) {
    QByteArray data = loadDataJson(name);
    if (data.isEmpty()) {
        if (err) *err = QStringLiteral("file empty or not found: %1").arg(name);
        return std::nullopt;
    }
    QJsonParseError perr;
    auto doc = QJsonDocument::fromJson(data, &perr);
    if (perr.error != QJsonParseError::NoError) {
        if (err) *err = perr.errorString();
        return std::nullopt;
    }
    return doc;
}

} // namespace
```

**调用方改造**:
```cpp
// 之前 (KnotService):

for (const QString& p : paths) { file.setFileName(p); ... }

if (!doc) { Logger::error(...); return false; }
// 直接用 doc->array() / .object()
```

**影响**: 11 个 service 的 `loadFromJson` 函数全部简化（删 ~30 行 fallback），新增 1 个工具类，零功能变化。
