## 背景

用户提问:衣物推荐是否考虑温度/风速/海拔,以及人体穿戴体感是否有关系。

经讨论,确定方向:衣物推荐应基于**体感温度**算法,综合考虑气象温度、风速、海拔、湿度、日照、人体代谢、个人体质。

## 核心算法(已讨论,未实施)

### 体感温度公式

```
体感温度 = 气象温度 - 海拔修正 - 风寒指数 - 湿冷补偿 - 阴天补偿 + 活动强度 + 个人体质
```

| 因素 | 修正量 |
|---|---|
| 海拔 | 每升 1000m 气温 -6.5°C(干绝热递减) |
| 风速 | NOAA 风寒公式(0°C 时 5m/s 风 ≈ -10°C) |
| 湿度 | >80% 时 -1.5°C(湿冷) |
| 阴天 | -1.5°C |
| 行军 | +3°C / 静坐 -2°C |
| 怕冷体质 | -2°C / 怕热 +2°C |

### 三层穿衣原则

```
底层(base) → 排汗速干
中层(middle) → 保暖锁空气
外壳(outer) → 防风/防水/透气
```

## 8 条新增规则(规划)

| ID | 名称 | 条件 | 触发装备 |
|---|---|---|---|
| R_WIND_HARD | 大风需硬壳 | wind_speed > 5 m/s | 硬壳冲锋衣 |
| R_RAIN_HEAVY | 暴雨需雨衣 | rainfall > 5mm/h | 雨衣+防水手套 |
