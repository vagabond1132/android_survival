# 08-地图主页改版讨论

> 2026-09-10/11 讨论。决定把 HomePage 替换为 MapPage 主页, 5.5 天工作量, P1 阶段。

## 需求来源

用户提出: 把首页展示样式改为地图展示, 包含当前位置, 有记录/导航/周边线路功能, 还可以选择省份/展示路线, 选路线后提示信息并加载到地图, 后续展示分析图 (海拔/速度等)。

后续细化: **上方地图 + 默认前进方向在上 + 方向指针 + 右侧标注/拍照/居中按钮 + 下方 4 标签 BottomSheet (记录/导航/周边/查找)**。

## 需求详情 (P1 范围)

### 功能清单

1. 地图为主视图 (替换现有 HomePage)
2. 当前位置标记 (QtPositioning)
3. 方向指针 (中央叠加, 旋转随 heading)
4. 右侧浮动列 (3 按钮):
   - 标注 (在当前位置加 MapCircle + 文字)
   - 拍照 (调 Android Intent.ACTION_IMAGE_CAPTURE, 保存到本地)
   - 居中 (地图中心 = 当前位置)
5. BottomSheet (Drawer 模拟, Qt 6.7 Material 无原生) 4 标签:
   - 记录: track 启动/暂停/停止 + 拍照
   - 导航: 历史轨迹列表, 加载到地图
   - 周边: 路线按距离 + 类型/难度/时长筛选
   - 查找: 路线按城市/名称/类型/难度/时长筛选 (不限位置)

### 非目标 (Non-goals)

- ❌ polyline 真实轨迹 (P2 数据增强)
- ❌ 海拔剖面图 (P2 需 elevation profile)
- ❌ 速度/坡度分析图 (P3 实时分析)
- ❌ 实时 GPS 轨迹对比 (P3)
- ❌ 路线评分/历史 (V2)
- ❌ POI 数据接入 (V2)
- ❌ 离线瓦片 (P2 之后)

## 技术选型 (已确认)

- **QtLocation 6.7** + osm 瓦片 (够用)
- **QtPositioning** 提供 direction (heading)
- **QtCharts** CMake 已 link, **P1 阶段不上图**, P2/P3 阶段再讨论
- **BottomSheet** 用 `Drawer { edge: Qt.BottomEdge }` 模拟
- **Tab 切换** 用 `TabBar + StackLayout`, 与现有 `EquipmentPage` / `SurvivalPage` 模式一致
- **拍照** Android Intent, 需 `AndroidPlatform::takePhoto(callback)` 新增 (C++ ~30 行)

## 待确认的 UI 决策 (讨论中)

### 路线 vs 轨迹 Tab 4 范围

最终选 **Tab 4 查路线 (749 routes, 按城市/名称/类型/难度/时长筛选)**。
跟 Tab 3 区别: Tab 3 依当前点距离过滤, Tab 4 不限位置。

### 样式主题

- 现有 `Material.theme: Material.Dark` + `Material.accent: Material.Orange` + `Material.primary: Material.BlueGrey`
- 50+ 处硬编码颜色 (#1976D2 / #D32F2F / #FF5722 / ...) **不统一**
- 建议建 `Theme.qml` 单例统一 (但 P1 阶段不动, V2 清理)

### 拍照按钮位置

- 选 **右侧浮动列中部** (按钮: 标注 / 拍照 / 居中)
- 不放 SOSButton 旁边, 避免误触

### 4 标签顺序

| Tab | 顺序 | 功能 |
|---|---|---|
| 1 | 📍 记录 | track 启动/暂停/停止 + 拍照 |
| 2 | 🧭 导航 | 历史轨迹加载 |
| 3 | 🗺 周边 | 按距离 + 筛选 |
| 4 | 🔍 查找 | 按城市/名称 + 筛选 |
