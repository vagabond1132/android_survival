# 启动崩溃排查与图标重做

> 记录 2026-09-03 基于 tombstone.txt 排查的本项目启动崩溃隐患 + 图标重做
> 涵盖 14 项代码修复 + 5 个新文件 (图标生成脚本 + 2 个 mipmap 资源)

---

## 1. 排查起点

用户提供了 `tombstone.txt` (333 KB, 2725 行) 抓取自真机。tombstone 报告:

- **进程**: `com.xingin.tiny.daemon.e` (uid 10006, 行信小钛 helper)
- **信号**: SIGABRT, code -1 (SI_QUEUE)
- **abort message**: `Native registration unable to find class 'com/android/internal/os/RuntimeInit'; aborting...`
- **调用栈关键帧**: `jniRegisterNativeMethods → register_com_android_internal_os_RuntimeInit → startReg → start`
- **设备**: HONOR PGT-AN00, Android 9.0.0.169, arm64

**结论**: 崩溃进程**不是**本项目 (本项目 applicationId 是 `com.outdoor.survival`)。崩溃发生在**系统框架代码** `libandroid_runtime.so` 内部, 是设备/系统层问题。

但其崩溃**模式** — "JNI 注册时找不到类" — 在本项目启动链路上有同源隐患。

## 2. 本项目启动链路分析

```
[系统层]  app_process64 → ART → libandroid_runtime
[项目层]  AndroidManifest
           ├── .OutdoorSurvivalApp  (Application.onCreate)
           │     └── System.loadLibrary("OutdoorSurvival")
           └── QtActivity  (Qt 6 自带)
                 └── JNI_OnLoad / Java_... 符号解析
                       ├── Java_com_outdoor_survival_EmergencyService_nativeUpdateLocation
                       └── QJniObject 调用 QtNative.activity()
[QML层]   engine.loadFromModule("OutdoorSurvival", "Main")
           └── Map / Page / Service context property
```

## 5. 图标重做

### 5.1 旧图标问题

所有 mipmap 图标文件 (`ic_launcher.png` / `ic_launcher_round.png` / `ic_launcher_foreground.png` × 5 密度) 全是**纯蓝色 #1976D2** (192x192 仅 616 字节压缩后大小) — 占位符, 用户看到"蓝色圆/方块"。

### 5.2 新图标设计

户外生存主题:
- **天空**: 深蓝紫 (#1C3359) → 暖橙 (#F28E2B) 渐变 (落日)
- **太阳**: 暖黄 (#FFDC82) + 柔光晕
- **远山**: 灰蓝 (#4A5F73)
- **近山**: 深绿 (#264033)
- **帐篷**: 米白 (#E4DCC3) + 深色门 (#34291E)

### 5.3 新文件

| 文件 | 用途 | 大小 |
|------|------|------|
| `scripts/generate_icons.py` | 纯 stdlib (zlib + struct) PNG 生成器 | ~7KB |
| `android/res/mipmap-*/ic_launcher.png` | 完整图 (旧设备 API < 26 用) | 1.1KB (mdpi) → 10KB (xxxhdpi) |
| `android/res/mipmap-*/ic_launcher_round.png` | 同上 (圆角 mask) | 同上 |
| `android/res/mipmap-*/ic_launcher_foreground.png` | **透明背景 + 居中 66% 区域 logo** (Android 8+ adaptive icon) | 510B → 4KB |
| `android/res/values/ic_launcher_background.xml` | `#1976D2` → `#1C3359` (与天空呼应) | 改 |

### 5.4 Android 兼容性

- **API < 26**: 直接用 `ic_launcher.png` (满版设计)
- **API 26+**: `mipmap-anydpi-v26/ic_launcher.xml` (adaptive icon), 背景色 `#1C3359` + 前景透明 logo (Android 系统按 66% 居中裁剪 + mask)

## 7. 经验总结

1. **JNI 字符串类名漂移是 Android 上最常见的崩因**。每次 Qt 主版本升级 / NDK 升级 / 设备切换, 必须重审所有 `org/qtproject/...` `android/...` 字符串类名
2. **QJniObject 必须 isValid 防御**。`callStaticObjectMethod` 返回 invalid 对象是常态 (类找不到 / 权限不足 / 设备不支持), 不防御必崩
3. **Application.onCreate 显式 loadLibrary** 是防 R8 + 启动期时序竞争的最稳位置
4. **图标不能用单色 PNG 占位**。Android 8+ adaptive icon 区分 background (color) 和 foreground (PNG), 前景必须是透明背景 + 居中 logo
5. **MapPage 用开源 OSM 插件**。Qt 6 商业 mapbox 插件已移除
