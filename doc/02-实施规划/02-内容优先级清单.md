## 一、总则

### 1.1 文档目的

- 明确**先做什么、后做什么**
- 资源有限时**先救命、再学习**
- 避免做"锦上添花"的功能却漏掉关键功能
- 团队成员**统一优先级认知**

### 1.2 排序原则

| 原则 | 权重 | 解释 |
|---|---|---|
| **救命价值** | 40% | 直接影响生命安全 |
| **使用频次** | 25% | 实际被打开使用的次数 |
| **差异化** | 20% | 相对其他 App 的独特性 |
| **建设成本** | 15% | 投入产出比 |

### 1.3 内容分层

```
P0 必做 - 救命核心
  ↓
P1 应做 - 核心功能
  ↓
P2 宜做 - 增强体验
  ↓
P3 可选 - 远期扩展
```

## 三、内容分类与优先级

### 3.1 一级优先级（救命类）

**判断标准**：如果用户**没看到这条内容就可能受伤/死亡**，则必须做。

```
救命类
├── 1.1 急救（心搏骤停、大出血、蛇咬、中毒）
├── 1.2 SOS 紧急呼叫
├── 1.3 致命动植物警示（10 大毒蛇、致命蘑菇）
├── 1.4 极端天气应对（雷击、雪崩、洪水）
└── 1.5 基础求救信号
```

### 3.2 二级优先级（核心功能）

**判断标准**：这是 App 的**差异化功能**，用户主要使用它。

```
核心功能
├── 2.1 拍照 AI 识别（动植物）
├── 2.2 取火 / 庇护所 / 工具（生活技巧）
├── 2.3 绳结（户外必备技能）
├── 2.4 防虫防蛇（户外特定需求）
└── 2.5 路线 + 难度（中国本土）
```

### 3.3 三级优先级（增强体验）

**判断标准**：让 App **更好用、更丰富**，但不紧急。

```
增强体验
├── 3.1 应急储备清单
├── 3.2 综合手册（装备 / 出行 / 安全）
├── 3.3 详细动植物图鉴
└── 3.4 装备评测
```

### 3.4 四级优先级（远期）

**判断标准**：做完整 App 后再考虑。

```
远期
├── 4.1 药用植物图鉴
├── 4.2 户外文化 / 历史
├── 4.3 进阶技能
└── 4.4 区域特色
```
