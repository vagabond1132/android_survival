## 三、核心层 (core/)

### 3.1 App.h / App.cpp — 应用主类
- **职责**：全局单例,初始化所有 12 个服务
- **核心方法**：
  - `initialize()` - 启动所有子系统
  - `shutdown()` - 优雅关闭
  - 12 个 `get*Service()` 访问器
- **依赖**：所有子系统
- **状态**：`m_ready` 在所有子系统就绪后为 true

### 3.2 Config.h / Config.cpp — JSON 配置
- **职责**：应用配置(主题/单位/默认值)
- **核心方法**：`get/set/contains/save/load`
- **存储路径**：`{appData}/config.json`

### 3.3 Logger.h / Logger.cpp — 日志
- **6 级**：Trace/Debug/Info/Warn/Error/Fatal
- **文件轮转**：5MB × 5 个备份
- **线程安全**：QMutex
- **存储路径**：`{appData}/logs/app_YYYYMMDD.log`

### 3.4 Database.h / Database.cpp — 多数据库
- **6 个数据库**：
  - 明文：species / firstaid / survival_knots / routes / photos
  - 加密：user / settings
- **优化**：WAL 模式、缓存、外键
- **2026-09-21 阶段 J**：PRAGMA user_version 迁移机制完整化
  - `static constexpr int kCurrentSchemaVersion = 2`
  - `migrate()` → `migrateToLatest()` 链 → 写新值
  - 加表/加列时: `migrate_X_to_Y()` + `kCurrentSchemaVersion+1`
  - knot_progress 表归 KnotService::ensureSchema() 拥有 (Survival db)

## 四、急救模块 (lifesaver/)

### 4.1 FirstAidService — 急救条目
- **数据规模**：35 条 + 8 个决策节点 + 3 个 Kit 模板（`firstaid_entries.json`）
- **Q_PROPERTY**：`totalEntries`、`criticalCount`（`NOTIFY dataChanged`）
- **5 大分类**：`Category{Critical, Trauma, Environment, Poison, Emergency}`
  （`enum class`，QML 端须写 `FirstAidService.Category.Critical`）
- **紧急度**：`Urgency{Info=1, Low=2, Medium=3, High=4, Crisis=5}`
  （原 `Critical` 改名 `Crisis`，避免与 `Category::Critical` 的 MOC 注册冲突）
- **核心 API**（12 个 Q_INVOKABLE）：
  - `getAllEntries()` / `getById(id)` - 全量 / 详情
  - `getByCategory(cat)` / `getByUrgency(urgency)` / `getCritical()`
  - `search(keyword)` - 关键词
  - `getDecisionRoot(entryId)` / `getDecisionNode(nodeId)` / `getDecisionPath(entryId, …)`
  - `getKitTemplates()` / `getKitTemplate(scenario)`
  - `getRelatedSpecies(entryId)` - 关联危险物种
- **数据**：`assets/data/firstaid_entries.json`

### 4.2 EmergencyService — SOS 紧急
- **核心 API**：
  - `triggerSOS()` / `cancelSOS()` / `isSosActive()`
  - `call120/110/119()` / `callNumber(num)`
  - `sendSosSMSToAll()` / `sendSMS(num, text)`
  - 紧急联系人 CRUD：getContacts/addContact/deleteContact/setPrimary (2026-09-20 Phase 4: removeContact → deleteContact)
  - `getCurrentLocation()` - 当前位置
- **SOS 流程**：长按 3 秒 → 拨 120 → 1.5s 后群发短信 → 持续 GPS 上报

### 4.3 DecisionEngine — 已归档（2026-10-16）
- `src/firstaid/DecisionEngine.{h,cpp}` 是一份**从未接线**的桩：`startSession/selectOption`
  返回硬编码的"3 步终止"文案，源码注释写明"实际应该通过 FirstAidService 查询"。
- 核查结论：`ServiceRegistry` 不构造它、QML 不 import 它 → 已从 `CMakeLists.txt` 移除源条目
  并归档到 `.bak_deadcode_20261016/src/firstaid/`（本轮移除的是 LIFESAVER_SOURCES 分组里的 2 行）。
- **决策树的线上实现**：`FirstAidService.getDecisionRoot/getDecisionNode/getDecisionPath`
  + `qml/pages/FirstAidDecisionPage.qml`。

## 六、动植物图鉴 (species/) V2 重构

> 2026-08-27 V2 重构:从 SpeciesService 拆分出 4 个独立 Service + 共享索引 + HSV 颜色匹配

### 6.1 FieldGuideIndex — 共享索引
- **职责**:从 4 个 JSON 加载 + 内存索引(按 id/kingdom/category)
- **来源**:`assets/data/field_guide_{plants,animals,insects,mushrooms}.json`

### 6.2 PlantService — 植物图鉴(339 种)
- **数据**:鲁晋冀豫 4 省 100 种(可食野菜 35+ 野果 15+ 药用 20+ 毒 20+ 观赏 10+)
- **API**:
  - `getAll() / getById(id) / search(keyword)`
  - `getByCategory(cat) / getEdible(month) / getPoisonous() / getMedicinal() / getDangerous(minLevel)`
  - `getByProvince(province) / getByMonth(month) / getByProvinceAndMonth(province, month)`
  - `getAvailableProvinces() / getAvailableCategories()`
  - `getAlongRoute(routeId, month)` ← 路线联动
  - `getLookAlike(id)` ← 易混种
  - `getByFirstAid(id)` ← 急救联动
  - `recordLocation(plantId, lat, lon, note)` / `getLocationsByPlant(plantId)` / `getLocationsNear(lat, lon, radiusKm)` ← 地图联动
  - `matchByColor(userColorHSV, topK)` ← HSV 匹配,返回 Top-K + similarity%

### 6.3 AnimalService — 动物图鉴(139 种)
- 涵盖蛇(15 毒 + 5 无毒)/兽(5)/两栖(3)/其他(20+)
- API 与 PlantService 同构
- 特有:`getSnakes(venomousOnly)` / `getMammals()`

### 6.4 InsectService — 昆虫图鉴(114 种,独立)

### 6.5 MushroomService — 蘑菇图鉴(67 种,独立)

### 6.6 FieldGuideHistory — 浏览历史(原 RecognitionStorage)

- 统计:`plantCount()` / `animalCount()` / `insectCount()` / `mushroomCount()` / `statsByKingdom()`

### 6.7 HSV 拍照降级(无 AI 推理)
- 所有 4 个 Service 都有 `matchByColor(userColor, topK)`
- 算法:用户图片 → 224×224 → HSV 直方图(48 维) → 余弦相似度 → Top-K
- 返回:每条带 `similarity` 字段(0-100)
- 强制免责声明("本结果仅供参考,务必对照图鉴二次确认")
- **完全离线,无 AI,无法律责任**
